企业何时必须持有进口许可证？

进口许可证

并非所有从海外引进货物的活动都需要相同的进口许可证。所需许可证的类型取决于企业的身份、货物的用途，以及货物本身的类别。本文概述使企业需要办理进口许可证的一般情形。

API-U 与 API-P：两种不同途径

一般而言，进口商识别编号分为两种主要类型：

  • API-U（一般进口商识别编号） —— 适用于进口货物用于贸易（而非自用于生产）的企业。
  • API-P（生产型进口商识别编号） —— 适用于进口原材料、辅助材料或资本货物以供自身生产使用的企业。

选错 API 类型可能影响进口合规性，甚至在清关过程中造成障碍。

使进口许可证成为强制要求的情形

  • 企业定期从海外引进货物，用于在国内市场转售。
  • 制造企业进口国内供应商无法提供或供应不足的原材料或零部件。
  • 进口货物属于需要 API 以外额外进口许可的类别，例如涉及安全标准、卫生要求或受管制货物类别。

常被忽视的额外进口许可

除 API 外，部分货物类别在进口流程开始前，还需要相关技术部委/机构颁发的额外许可或推荐函。仅办理 API 而未核实是否需要额外许可的企业，存在货物在海关被扣留的风险。

各货物类别的进口许可规定可能随适用贸易政策变化。建议在进口前重新确认此状态，尤其是新的货物类别。

总结

企业的进口许可需求由其经营身份（是否为生产商）与所进口货物类别共同决定。从一开始就确保办理正确类型的许可证，有助于避免清关流程中的障碍。
